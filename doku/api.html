Key Model Classes

  • ComposerData - Contains project name and collections of packages

  • Conflict - Represents a detected dependency conflict
  • Solution - Represents a suggested resolution for a conflict

CLI Interface

The CLI interface provides a command-line tool for interacting with PackSolver.

PackSolverCommand

Main command class for the CLI interface.

use Symfony\Component\Console\Command\Command;

{
    /**
     * Configure the command
     */
    protected function configure(): void
    {
        $this->setName('analyze')
            ->setDescription('Analyze composer dependencies for conflicts')
            ->addArgument('path', InputArgument::OPTIONAL, 'Path to the project', '.')

Usage Examples

# Basic usage (current directory)
./bin/packsolver

# Analyze a specific project
./bin/packsolver /path/to/project

# Output in JSON format
./bin/packsolver --json

# Show detailed information
./bin/packsolver -v
