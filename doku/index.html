Project Overview

PackSolver is a developer tool designed to simplify the process of resolving PHP Composer dependency conflicts. When package version requirements collide and block your workflow, this tool analyzes your composer.json and composer.lock files, detects conflicting dependencies, and provides clear, actionable suggestions to help you get back to coding faster.

Whether you're maintaining a complex application or troubleshooting a tricky update, PackSolver makes dependency management more transparent and less frustrating.

Key Components

  • Parser: Extracts dependency information from composer.json and composer.lock files
  • Analyzer: Detects conflicts between package dependencies
  • Resolver: Generates actionable solutions for resolving conflicts
  • CLI Interface: Command-line interface for interacting with the tool

Features

  • Parse composer.json and composer.lock files to extract dependency information
  • Detect conflicts between package dependencies
  • Generate multiple solution strategies for resolving conflicts:
    • Update packages to compatible versions
    • Relax version constraints
    • Suggest alternative packages
    • Remove conflicting dependencies
  • Provide clear, actionable steps for implementing solutions
  • Output results in human-readable or JSON format

Installation

You can install PackSolver globally using Composer:

composer global require tuxonice/packsolver

Or add it to your project as a development dependency:

composer require --dev tuxonice/packsolver

Requirements

  • PHP 8.0 or higher
  • Composer 2.0 or higher

Development

To contribute to PackSolver, follow these steps:

Setting Up the Development Environment

git clone https://github.com/tuxonice/packsolver.git
cd packsolver
composer install

Running Tests

composer test

Code Style

PackSolver follows PSR-12 coding standards. You can check your code style with:

composer cs

And automatically fix style issues with:

composer cs-fix
